# Cyronethic-CTF

Tempat belajar dan berlatih Capture The Flag (CTF).

## Kategori

- **Web Exploitation** — SQL injection, XSS, SSRF, dll.
- **Cryptography** — Enkripsi, hashing, encoding.
- **Reverse Engineering** — Binary analysis, decompilation.
- **Forensics** — File analysis, steganography, memory forensics.
- **Pwn (Binary Exploitation)** — Buffer overflow, ROP, format string.
- **Misc** — Scripting, OSINT, trivia.

## Struktur

```
├── web/          # Web exploitation challenges & writeups
├── crypto/       # Cryptography challenges & writeups
├── reverse/      # Reverse engineering challenges & writeups
├── forensics/    # Forensics challenges & writeups
├── pwn/          # Binary exploitation challenges & writeups
├── misc/         # Miscellaneous challenges & writeups
├── scripts/      # Reusable tools & scripts
└── notes/        # Catatan & cheat sheets
```
